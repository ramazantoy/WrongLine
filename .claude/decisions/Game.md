# WrongLine (oyun kararları)

Oyunun kararları ve doğrulananları burada; template'e gidenler dosyanın sonunda. Framework kararları diğer
dosyalarda; bu dosya template'te yok, bu yüzden cherry-pick'lerle çakışmaz. Karar değişirse satır silinmez; eskisinin üstü
çizilir, yenisi eklenir. Dosya büyürse özellik başına bölünür (`Game.<Özellik>.md`).

  toplam sabit.
- **Play durma:** `RoadPiecePool.Release` sahnesi gitmiş parçayı geri vermiyor (yukarıdaki "Play durma" satırı); düzeltmeden
  sonra 600 kare + durdurma 0 hata.
- **Uyarı:** duraklatılmış Editor'da kare adımlamak Unity'nin kendi `JobTempAlloc` uyarılarını (15) basıyor; road koduyla ilgili
  bir iş yok, baseline ölçülmedi.
- **Denenmeyen:** Android cihaz (ilk Android build sonraya kaldı), FBX import önerisi, gerçek `Pools`'un EditMode testi
  (internal; sahte havuzla test edildi, gerçeği Play'de ölçüldü).
